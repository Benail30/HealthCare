=================================================================
COMMANDS TO UPDATE MAIN BRANCH ON GITHUB
=================================================================

Copy and paste these commands one by one:

# Step 1: Switch to main branch
git checkout main

# Step 2: Pull latest main (if any changes)
git pull origin main

# Step 3: Merge dev into main
git merge dev -m "Release: Merge dev to main - Complete DevOps project with CI/CD pipelines"

# Step 4: Create version tag
git tag -a v1.0.0 -m "Release v1.0.0: Healthcare DevOps Project - Complete implementation"

# Step 5: Push main branch to GitHub
git push origin main

# Step 6: Push version tag to GitHub
git push origin v1.0.0

# Step 7: Verify everything
git log --oneline -5
git tag -l
